# Bonjou Design Context

## Visual Direction

Bonjou is a technical brand surface for developers using laptops in a dim office, classroom lab, or hackathon room where terminals are already open and the network is local. The site should be dark because the product context is terminal-native and often used in low-glare environments, but the dark mode must be readable and refined rather than black-and-neon.

## Color Strategy

Restrained with a confident cyan accent and small violet/lime secondary signals drawn from the existing logo. Neutrals are green-cyan tinted OKLCH values. Accent color should be reserved for primary CTAs, active state, command prompts, network signals, and focus rings.

## Typography

Use one precise contemporary sans family plus a matching mono. Avoid huge novelty display type. Headings should be confident but compact, with clear hierarchy and comfortable line lengths. Code and commands should be highly legible.

## Layout

The first viewport must show the product name, core value proposition, install/source actions, and a credible product visual. Use information-dense but breathable sections. Prefer dividers, rows, diagrams, and terminal surfaces over repeated generic cards. No nested cards.

## Components

- Buttons: compact, high contrast, visible focus, icon plus label.
- Terminal surfaces: purposeful product previews, not oversized decoration.
- Install area: tabs by OS, copy feedback, release links.
- Command reference: searchable, grouped, compact.
- Security section: architecture flow and explicit limitations.

## Motion

Use subtle CSS transitions and optional terminal typing only. Content must remain visible without relying on scroll-triggered opacity. Respect `prefers-reduced-motion`.
