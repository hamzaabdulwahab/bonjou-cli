features

Built for real local work

Everything you need to move messages and files across a local network, without the overhead of cloud services or shared drives.

Discovery

Auto-Discover Peers

Bonjou uses UDP broadcast to automatically find other users on your subnet. No configuration, no manual IP entry. Just run and connect.

Chat

Terminal Chat

Send direct messages, multi-recipient messages, or broadcasts to everyone on the network. All from simple @ commands in your terminal.

Transfer

Files & Folders

Send a single file or an entire directory with @file and @folder commands. The receiver inspects metadata before approving.

Approval

Metadata-First Queue

Incoming transfers enter a pending queue. View file names, sizes, and senders before writing a single byte to disk. Full control.

Wizard

Guided Wizard Mode

Prefer menus over commands? The @wizard guides you through message, file, folder, and broadcast flows interactively.

Security

Trust Controls

Inspect, replace, or remove pinned peer keys. TOFU identity pinning with @known, @fingerprint, @trust, and @forget commands.

workflow

Discover, send, inspect, approve

Four steps from zero to file transfer. No setup, no configuration, no accounts.

security

Security claims with stated limits

What Bonjou protects and what it does not. Full transparency from the repository security model.

What is Protected

Protocol v2 protections as documented in the security model.

  • AES-256-GCM authenticated encryption for every envelope
  • Per-chunk stream authentication for corruption detection
  • Trust-on-first-use (TOFU) peer identity pinning
  • Replay rejection with per-peer nonce cache
  • Path safety checks confine writes to receive root

Known Limitations

Honest limits from the current security model.

  • Forward secrecy is not yet available
  • config.json stored on disk in plaintext (mode 0600)
  • Chat content logged in plaintext to chat.log
  • Discovery is same-subnet only (no routers/VLANs)
